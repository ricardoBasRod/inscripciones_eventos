# Gestión de Eventos - Repositorio Principal

Aplicación full-stack para gestionar eventos e inscripciones.

## 📁 Estructura del Proyecto

```
inscripciones_eventos/
├── frontend/                # Aplicación Angular
│   ├── src/
│   ├── angular.json
│   ├── package.json
│   └── ...
├── backend/                 # API FastAPI
│   ├── app/
│   ├── requirements.txt
│   └── main.py
├── README.md
├── .gitignore
└── ROADMAP.md
```

## 🚀 Quick Start

### Frontend (Angular)
```bash
cd frontend
npm install
npm start
```

### Backend (FastAPI)
```bash
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

Accede a:
- Frontend: http://localhost:4200
- Backend: http://localhost:8000
- Docs: http://localhost:8000/docs
