❓ PREGUNTAS FRECUENTES:

P: ¿Dónde cambio la URL de OneDrive?
R: backend/.env → ONEDRIVE_URL

P: ¿Por qué no aparecen los datos?
R: 1. Verifica que Backend está corriendo (terminal 1)
   2. Verifica que Frontend conecta (F12 → Network)
   3. Lee CONEXION_ONEDRIVE.md → Troubleshooting

P: ¿Cómo agrego más columnas?
R: Solo agrega en el Excel. Frontend y Backend se adaptan.

P: ¿Cómo despliego?
R: Ver ESTRUCTURA.md → Deployment (Docker, Azure, Heroku)

P: ¿Cómo agrego autenticación?
R: Ver ROADMAP.md → Fase 2

🐛 TROUBLESHOOTING RÁPIDO:

Problema                         Solución
──────────────────────────────────────────────────────────
Backend dice "Port 8000 in use"  Cambia en backend/.env
Frontend dice "Port 4200 in use" ng serve --port 4201
npm install fallido              rm -rf node_modules && npm install
pip install fallido              pip install -r requirements.txt --user
Backend no conecta OneDrive       Ver CONEXION_ONEDRIVE.md
