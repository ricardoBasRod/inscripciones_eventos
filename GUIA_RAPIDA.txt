⚡ OPCIÓN 1: Ejecución Individual (RECOMENDADO para principiantes)
════════════════════════════════════════════════════════════════

Abre 2 terminales diferentes:

TERMINAL 1 - Backend (Puerto 8000):
  Windows (PowerShell/CMD):
    .\run-backend.bat

  Mac/Linux (Bash):
    bash run-backend.sh

TERMINAL 2 - Frontend (Puerto 4200):
  Windows (PowerShell/CMD):
    .\run-frontend.bat

  Mac/Linux (Bash):
    bash run-frontend.sh

Luego abre tu navegador:
  http://localhost:4200


⚡ OPCIÓN 2: Ejecución Automática (RECOMENDADO para usuarios avanzados)
════════════════════════════════════════════════════════════════

Windows:
  1. Abre PowerShell o CMD
  2. Ejecuta: .\start.bat
  3. Se abrirán 2 ventanas automáticamente

Mac/Linux:
  1. Abre Terminal
  2. Ejecuta: bash start.sh
  3. Ambos servicios se ejecutarán en la misma ventana


📌 PRIMER SETUP (Una sola vez)
════════════════════════════════════════════════════════════════

Windows:
  .\setup.bat

Mac/Linux:
  bash setup.sh

Esto instalará:
  ✓ Entorno virtual Python
  ✓ Dependencias Backend (FastAPI, Pandas, etc)
  ✓ Dependencias Frontend (Angular, etc)


📍 ACCESO A LOS SERVICIOS
════════════════════════════════════════════════════════════════

Una vez ejecutando:

Frontend:           http://localhost:4200       (Tu app)
Backend:            http://localhost:8000       (API)
Swagger Docs:       http://localhost:8000/docs  (Documentación)
Health Check:       http://localhost:8000/health


🎯 CÓMO USAR LA APP
════════════════════════════════════════════════════════════════

1. Abre http://localhost:4200 en tu navegador
2. Verás un botón "📥 Descargar Información"
3. Haz clic en el botón
4. Espera a que cargue (verás un spinner)
5. ¡La tabla se llenará con tus datos de OneDrive! ✨


⚙️ CONFIGURAR TU ONEDRIVE (Si tienes otro archivo)
════════════════════════════════════════════════════════════════

1. Abre: backend/.env

2. Busca la línea:
   ONEDRIVE_URL=https://1drv.ms/x/c/...

3. Reemplázala con tu URL:
   - Ve a tu OneDrive
   - Click derecho en el archivo Excel
   - "Compartir" → "Copiar enlace"
   - Pega la URL en backend/.env

4. Guarda el archivo (Ctrl+S)

5. El Backend detectará automáticamente los cambios

❓ PROBLEMAS COMUNES
════════════════════════════════════════════════════════════════

P: "Entorno virtual no encontrado"
R: Ejecuta primero: setup.bat (Windows) o bash setup.sh (Mac/Linux)

P: "Dependencias no instaladas"
R: Ejecuta: setup.bat o bash setup.sh

P: "Puerto 4200 ya está en uso"
R: En otra terminal, ejecuta: ng serve --port 4201

P: "Puerto 8000 ya está en uso"
R: Edita backend/.env y cambia: PORT=8001

P: "Backend no responde"
R: Verifica que la Terminal 1 está ejecutando .\run-backend.bat

P: "Frontend dice error de conexión"
R: Verifica que Backend está corriendo en http://localhost:8000/health

P: "La tabla está vacía después de descargar"
R: Ver archivo: CONEXION_ONEDRIVE.md → Troubleshooting

💡 TIPS
════════════════════════════════════════════════════════════════

• Los cambios en el código se actualizan automáticamente
• Abre DevTools (F12) para ver Network requests
• Backend logs aparecen en su terminal
• Puedes modificar estilos sin reiniciar
• Presiona Ctrl+C en la terminal para detener servicios
• Las 2 terminales pueden estar en la misma pantalla (tiling)


🔍 DEBUGGING
════════════════════════════════════════════════════════════════

Para ver qué está pasando:

1. Abre DevTools: F12
2. Ve a la pestaña "Network"
3. Haz clic en "Descargar Información"
4. Verás las requests:
   - GET http://localhost:8000/api/datos
   - Ver la respuesta JSON

Si hay error:
1. Abre pestaña "Console"
2. Verás mensajes de error
3. Busca en CONEXION_ONEDRIVE.md → Troubleshooting
